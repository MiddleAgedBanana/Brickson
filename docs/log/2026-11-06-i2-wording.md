## What changed and why

CodeRabbit's review of #83's last push found three wording points. All
three were agreed, none was in the app, and #83 had used its two fix
pushes, so they come here, before anyone runs the check.

- **Device check I2, step 4, stops the alarm between trials.** "Tap Help"
  and "Tap Get Attention" start it, and an alarm already sounding hides
  whether the next command started it.
- **The same step says what to do without Flexible Item Names.** Apple's
  iOS 26 guide does not have the setting, and its iOS 27 guide does. Each
  trial then runs once, and the other is written down as not available.
- **"The editor matches", not "Voice Control hears as",** in
  docs/DECISIONS.md, "Phrases named like Home's controls", and
  docs/HANDOFF.md, *Known gaps*: the match is Brickson's own comparison,
  and what Voice Control hears is unmeasured. The same words in
  [`log/2026-11-06-refuse-the-five-names.md`](2026-11-06-refuse-the-five-names.md)
  stay, because a log changes no other file in this folder, and the code
  comments that use them stay too, because this pull request changes no
  code.

The category a hand-made backup can name like a control, which the owner
was shown on 2026-11-06, was already in docs/HANDOFF.md, *Known gaps*.
