# Brickson logo artwork

A rounded B with a speech-bubble tail connects Brickson's name to its purpose:
a familiar place for a person's own words. The ivory-and-navy palette matches
the website. Broad shapes and open counters keep the mark readable at small sizes.

- `brickson-app-icon.png`: 1024×1024, opaque, ivory mark on navy. The square
  background extends to the edges so an icon mask can be applied later.
- `brickson-mark-transparent.png`: 1254×1254, navy mark with alpha transparency,
  for light backgrounds.

These are raster artwork deliverables, not an installed app icon or vector
masters. The current app asset catalog has not been changed. The opaque icon
was inspected at 64×64; dimensions and alpha were checked with `sips`.

## Generation

Created with the built-in Image Gen tool. The opaque artwork was resized to
1024×1024 with macOS `sips`, preserving the square aspect ratio.

App icon brief: design a custom rounded B monogram from speech-bubble forms
for an ALS communication app; dignified, calm and confident, broad sturdy
geometry, open counters, a short integrated speech tail; ivory #f7f5ee on
full-bleed navy #172e47, centered with generous margins; no text, medical
symbols, surrounding mockup or baked-in rounded-square border.

Transparent variant brief: preserve the exact silhouette, proportions,
counters and tail of the generated mark; change the ivory symbol to navy
#172e47; remove the background and counter interiors to true transparency;
no added text, border or shadow.
