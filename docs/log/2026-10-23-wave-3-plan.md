**The next pull requests, in order.** docs/ROADMAP.md gains *Wave 3:
the next pull requests, in order*: ten items, each with what it is in
plain words, the roadmap item and the rows of docs/ACCESSIBILITY.md it
covers, whether it changes Home's code, what it needs (a cloud session,
the owner's Mac, a device) and the Apple pages it rests on. The list was
asked for from R1 "Follows you" and the owner's first doors (Guided
Access and Assistive Access, App Intents and Shortcuts). Read against
the roadmap, three things set its order:

- **The layout engine is both R0 and R1.** R0 item 3 still needs it to
  end the scrolling the starter library does on some windows today, and
  R1's first bullet gives it input profiles. So it comes first as a
  plain type with no screen change (item 3), then Home moves onto it
  (item 4), then R0's typing (item 5) and iPhone Duo (item 6), and only
  then R1's profiles (items 8 and 9). Nothing moves past its release.
- **Only one pull request that changes Home's code is open at a time.**
  Items 4, 5, 6, 8 and 9 queue in that order; items 1, 2, 3, 7 and 10
  touch no Home code and run beside them. Items 1, 2 and 3 can start
  now.
- **Siri and Shortcuts are R2.** R0 leaves them out on purpose, and the
  roadmap says the vision is "Direction, not a licence to skip steps".
  Item 10 writes their work file only. Building them sooner is the
  owner's call; the recommendation is to keep them in R2.

**Can typing on Home start now?** Not yet. Its brief waits for R0 items
3 and 9, and Get Attention's record adds that the quick controls must
fit one row on wide windows first
([`2026-10-23-get-attention-on-home.md`](2026-10-23-get-attention-on-home.md),
*Follow-ups*, item 9). PR #38 put Get Attention and Stop on Home but
brought neither the layout engine nor the typing screen in Figma, so
typing is Wave 3 item 5, after Home moves onto the engine.

**Folding phones.** The owner asked (2026-10-23) how well a folding
phone such as iPhone Duo suits an AAC app.
[`docs/recon/2026-10-23/folding-phones-for-aac.md`](../recon/2026-10-23/folding-phones-for-aac.md)
answers with sources; docs/ROADMAP.md carries a summary. In short: a
larger iPhone, good for touch, switches and caregivers; the iPad stays
the main device once a person uses their eyes. One finding feeds item 6:
on iPhone Duo, Eye Tracking and Head Tracking work only fully open, and
the inner display goes dark where its camera sits while Eye Tracking is
on.

**docs/HANDOFF.md** points agents to the list from *Next steps, in
order*. docs/recon/README.md lists the new note.
